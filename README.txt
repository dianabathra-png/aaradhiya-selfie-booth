Aaradhiya's Food Truck Selfie Booth

Files:
- index.html: mobile-friendly selfie booth
- truck-background.png: cleaned food truck background

To use:
1. Upload BOTH files to the same folder on a web host that provides HTTPS.
2. Open the hosted index.html URL on a phone and allow camera access.
3. Test the selfie, capture, and download features.
4. Create a QR code pointing to the final HTTPS webpage URL.

Important:
- Camera access requires HTTPS (or localhost during local testing).
- The page uses MediaPipe from public CDNs, so the first load needs an internet connection.
- Camera processing happens in the browser; this page does not send the selfie to a server.
- Test on the actual phones customers will use before printing the QR code.
